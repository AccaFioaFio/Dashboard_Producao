Alerta de Corte por WhatsApp

Guia de conceitos e operação — Dashboard de Produção Fio a Fio
Atualizado em 13/10/2026

1. O que foi criado

Quando um produto tem o corte finalizado no dashboard (data final preenchida e aviso confirmado), o sistema pode avisar a equipe de duas formas:

  • E-mail — já existia (pode estar pausado).
  • WhatsApp — canal novo, ativo para 2 números.

O painel (“Lista do cortador” / Visão Geral) continua igual: o WhatsApp é só uma notificação extra, no mesmo momento do aviso.

2. Visão geral do fluxo

Usuário finaliza corte no Dashboard │ ▼ Dashboard (Next.js) monta a mensagem │ ├──► grava alerta no banco / nuvem (painel) ├──► e-mail (se ativo) └──► WhatsApp via Evolution API │ ▼ Número remetente (conectado) │ ▼ Destinatários (ex.: 5511… e 5511…)

3. Conceitos principais

3.1 Dashboard

Sistema web da fábrica onde se lança produção e corte. Ao salvar a data final e enviar para a lista do cortador, dispara o alerta.

3.2 Remetente × destinatário

Papel O que é Neste projeto
Remetente Número WhatsApp de onde a mensagem sai Celular conectado na Evolution (instância corte)
Destinatário Quem recebe o alerta Dois números configurados no .env.local

3.3 Docker Desktop

Programa que roda “caixas” (containers) no Windows. A Evolution API e o banco PostgreSQL ficam dentro dessas caixas. Sem o Docker Running, o WhatsApp automático não envia.

  • Precisa de virtualização ligada na BIOS (Intel VT-x).
  • Configurado para iniciar com o Windows (AutoStart).
  • O PC precisa estar ligado e logado.

3.4 Evolution API

Servidor intermediário que fala com o WhatsApp (via protocolo não oficial Baileys, parecido com WhatsApp Web). O dashboard não manda mensagem direto para a Meta: ele chama a Evolution em http://localhost:8080.

  • Instância corte — sessão WhatsApp usada para enviar.
  • API Key — senha da API: fioafio-corte-local.
  • Manager — painel visual: http://localhost:8080/manager.

3.5 QR Code / aparelho conectado

Para a Evolution usar um número, esse WhatsApp precisa estar vinculado como “aparelho conectado” (igual WhatsApp Web). Lê-se um QR no celular. Se desconectar, é preciso ler um QR novo.

4. Exemplo da mensagem

Formato real do aviso (mesma estrutura do e-mail):

O corte deste item foi finalizado. A costura pode seguir.

Pedido: 123456
Cliente: Exemplo Confecções Ltda

Produto: CAMISETA BASIC PRETA P
Código: 78901234
Quantidade real: 120
Início: 10/10/2026
Data final: 13/10/2026
Responsável: João

Com vários produtos no mesmo aviso, a primeira linha indica a quantidade de itens e cada produto aparece numerado (Item 1, Item 2…).

7. Variáveis de ambiente (WhatsApp)

WHATSAPP_EVOLUTION_URL=http://localhost:8080
WHATSAPP_EVOLUTION_INSTANCE=corte
WHATSAPP_EVOLUTION_APIKEY=fioafio-corte-local
WHATSAPP_CORTE_TO=5511986290100,5511982681980

8. Como reconectar se o celular desconectar

  1. Abra http://localhost:8080/manager
  2. Login: Server URL http://localhost:8080 e API Key fioafio-corte-local
  3. Instância corte → se estiver Disconnected → Get QR Code
  4. No celular: WhatsApp → Aparelhos conectados → Conectar → ler o QR
  5. Quando status ficar Connected / open, os envios voltam
Se o manager não abrir: confira se o Docker Desktop está Running e, no PowerShell: 
cd "c:\Projetos Cursor\Dashboard_Producao\tools\evolution"
docker compose up -d
.\setup.ps1

9. Manter tudo online

  • Docker Desktop com início automático no login.
  • Atalho em Inicializar do Windows: Evolution Corte Docker.
  • Containers com política unless-stopped (reiniciam sozinhos).
  • PC ligado e usuário logado; hibernar/desligar interrompe o envio.

10. Pausar ou reativar o WhatsApp

No arquivo app/actions/corte-producao.ts:

  • ENVIO_WHATSAPP_CORTE_PAUSADO = false → envia
  • ENVIO_WHATSAPP_CORTE_PAUSADO = true → não envia (painel continua)

O e-mail tem flag parecida: ENVIO_EMAIL_CORTE_PAUSADO.

11. Cuidados importantes

  • Uso interno (Baileys): não é a API oficial da Meta; evite spam.
  • Não desconecte o aparelho vinculado no WhatsApp sem necessidade.
  • Evite usar o mesmo número em vários WhatsApp Web ao mesmo tempo.
  • Reinicie o servidor Next.js após mudar o .env.local.
  • Ideal no futuro: chip/WhatsApp só para avisos (não o celular pessoal).
